Create a set of communications channels from the M33_ns to the M55 and from the M55 to the M33_ns.  Each of these channels sends a message to the other core that has a 16 bit opcode, a 16 bit payload length, and up to 4096 bytes of payload.  The m33_m55_shared memory should be used for all data in this protocol since it is reachable by both cores.  The life cycle of a message is that a message is allocated one one core then initialized by code.  The message is then sent to the other core.  The message remains active until the other core destroys the message making that memory available.  There should be a queue for messages to be sent and received. All of the opcodes should be stored in a single header file.  The first opcode should be a message sent from the M55 to the M33 which is an initialization complete message.  When this message is received by the M33, the M33 should light the green led.  Additionally another message type should be a log message from the M33 to the M55 which should cause the M55 to print the given message to standard out.
