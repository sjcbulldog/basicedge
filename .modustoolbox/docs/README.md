# ModusToolbox Workspace Reference

**Device:** PSE846GPS2DBZC4A | **BSP:** APP_KIT_PSE84_EVAL_EPC2 | **Workspace:** c:/mtbfw/graphics

## Architecture

This is a **dual-core** PSOC Edge MCU workspace featuring Cortex-M33 and Cortex-M55 processors.

| Core | Role | Projects |
|------|------|----------|
| **CM33** | Boots first, manages secure/non-secure contexts. Runs applications, NNLite NPU for low-power ML, connectivity stacks (WiFi/BLE) | proj_cm33_s, proj_cm33_ns |
| **CM55** | High-performance compute — GPU subsystem, Ethos-U55 NPU, DSP workloads | proj_cm55 |

**Boot sequence:** CM33 starts in secure mode → initializes system → boots non-secure app → wakes CM55 when needed for high-performance tasks.

**All projects:** proj_cm33_s, proj_cm33_ns, proj_cm55

> For inter-core communication, IPC setup, and dual-core boot synchronization details, see the `mtb-dual-core-setup` and `mtb-ipc-patterns` skills.

---

## Project Structure

Each core has its own project directory with independent Makefile, sources, and dependencies:

```makefile
# Key Makefile variables per project:
CORE=CM33|CM55                    # Target processor
CORE_NAME=CM33_0|CM55_0           # Core instance
VCORE_ATTRS=SECURE                # Secure project marker (proj_*_s only)
APPTYPE=flash                     # Execution from flash (XIP)
MTB_TYPE=APPLICATION               # Top-level workspace type (root Makefile only)
```

Shared libraries live in `../mtb_shared/` (outside the workspace directory, created by `getlibs`).

---

## Path Resolution (Critical for AI)

**All paths in build configuration are relative to the project directory, not workspace root.**

```
base_for_resolution = c:/mtbfw/graphics/<project_folder>/
absolute_path = normalize(base_for_resolution + relative_path)

Example:
  workspace:     c:/mtbfw/graphics
  project:       proj_cm33_s
  relative path: ../../mtb_shared/cmsis/release-v6.1.0/Core/Include
  base:          c:/mtbfw/graphics/proj_cm33_s/
  resolves to:   c:/mtbfw/graphics/../mtb_shared/cmsis/release-v6.1.0/Core/Include
```

Note: `../mtb_shared/` is **one level above** the workspace directory (shared across workspaces).

## KIT_PSE84_EVAL Information

### Display Failures

Displays connected to the KIT_PSE84_EVAL kit can get into a software-unrecoverable state, where communication becomes corrupted if the MCU is reset by the programmer during the middle of a transaction.  If the user reports the display is flashing a color sequence (white, red, blue, green, black for example), instruct the user to power cycle the entire EVK.
